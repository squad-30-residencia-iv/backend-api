# 🛠️ Implementação de Especificação (Implement Spec)

Você implementará uma especificação técnica ativa no repositório backend .NET.

1. Consulte o arquivo `agents.md` na raiz do projeto e siga as diretrizes de código e o catálogo de skills documentadas (ex.: padrões de log, validação e comandos).
2. Localize e leia o arquivo da spec em `docs/specs/in-progress/`.
3. Siga rigorosamente a ordem do checklist:
   - Contratos/Records
   - Validações e regras de negócio
   - Endpoints/Controllers
   - Testes unitários/integração
4. Não adicione campos, rotas ou comportamentos que não foram previstos na especificação ativa.
5. Não instale novos pacotes NuGet sem justificativa técnica e autorização explícita.
6. Ao concluir, execute ou instrua a execução da skill de testes: `dotnet test --verbosity normal`.
7. Marque os itens do checklist da spec como concluídos (`[x]`).
