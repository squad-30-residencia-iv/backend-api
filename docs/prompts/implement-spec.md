# 🛠️ Implementação de Especificação (Implement Spec)

Você implementará uma especificação técnica ativa no repositório backend .NET.

1. Localize e leia o arquivo da spec em `docs/specs/in-progress/`.
2. Siga rigorosamente a ordem do checklist:
   - Contratos/Records
   - Validações e regras de negócio
   - Endpoints/Controllers
   - Testes unitários/integração
3. Não instale novos pacotes NuGet sem justificativa técnica e autorização explícita.
4. Ao concluir, execute ou instrua a execução de `dotnet test --verbosity normal`.
5. Marque os itens do checklist da spec como concluídos (`[x]`).
