## 1. Contexto & Regras de Negócio

- O portal tem `/relatorios` com mock. Esta fatia expõe agregados reais da rede.
- Escopo: analista/gestor, `networkId` obrigatório + TenantGuard.
- Status de voucher sempre efetivo. Cancelados = `Cancelled`. Disponíveis = `Available` (+ `Provisional` conta em emitidos mas não em “ainda disponíveis” do KPI de resgatáveis: **Available** apenas).
- Emitidos = vouchers com status efetivo ≠ Discarded (confirmação ou provisório vivo conta como emissão operacional para o dashboard).
- Taxa = resgatados ÷ emitidos; null se emitidos = 0.
- `averageTicket` das regiões: sempre `null` nesta fatia (sem dado de ticket no modelo).
- CSV: no cliente (D8); sem endpoint de arquivo.

### Decisões

| # | Decisão |
|---|---|
| D-1 | `GET /api/v1/reports/overview?networkId=` + filtros opcionais `period` (`30d`\|`90d`\|`6m`), `campaignId`, `regionId`, `establishmentId`. |
| D-2 | Período filtra por `IssuedAt` UTC derivado do fuso da rede. |
| D-3 | Catálogo de filtros: `GET /api/v1/reports/catalog?networkId=` (campanhas, regiões, lojas ativas da rede). |

## 2. Contratos

```csharp
public record ReportOverviewResponse(
    ReportKpisResponse Kpis,
    IReadOnlyList<ReportMonthlyPointResponse> Monthly,
    IReadOnlyList<ReportStatusSliceResponse> StatusDistribution,
    IReadOnlyList<ReportCampaignRowResponse> TopCampaigns,
    IReadOnlyList<ReportRegionRowResponse> Regions);

public record ReportKpisResponse(int Issued, int Redeemed, int Expired, int Available, int Cancelled, decimal? UtilizationRate);

public record ReportMonthlyPointResponse(string Month, int Issued, int Redeemed, int Expired);
public record ReportStatusSliceResponse(string Status, int Count);
public record ReportCampaignRowResponse(Guid CampaignId, string Name, int Issued, int Redeemed, decimal? Rate);
public record ReportRegionRowResponse(Guid RegionId, string Name, int Vouchers, decimal? Rate, decimal? AverageTicket);

public record ReportCatalogResponse(
    IReadOnlyList<ReportOptionResponse> Campaigns,
    IReadOnlyList<ReportOptionResponse> Regions,
    IReadOnlyList<ReportEstablishmentOptionResponse> Establishments);

public record ReportOptionResponse(Guid Value, string Label);
public record ReportEstablishmentOptionResponse(Guid Value, string Label, Guid RegionId);
```
